# Application Under Test (AUT) Overview

## 1. Purpose

The AI-Assisted Quality Engineering Platform uses a demo e-commerce application as its primary Application Under Test (AUT).

The application provides a realistic user journey that allows the framework to demonstrate:

- UI automation
- Functional testing
- Negative testing
- Regression testing
- Smoke testing
- Test data management
- Page Object Model
- Synchronization
- API/UI validation
- Reporting
- CI/CD execution
- AI-assisted test generation
- AI-assisted failure analysis
